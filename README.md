# PlayerMapping

FFXIV / Dalamud向けのプレイヤー・モブ・FATE地図表示プラグインの配布リポジトリです。

## インストール

1. Dalamud設定の「試験的機能 / Experimental」にある「カスタムプラグインリポジトリ」に、次のURLを追加し、保存します。

   ```text
   https://raw.githubusercontent.com/konvarec/PlayerMappingCustomRepo/main/pluginmaster.json
   ```

2. プラグインインストーラーを開き直し、`PlayerMapping`をインストールします。
3. 初回に表示される画面で、配布元から案内された利用キーを入力してください。Observer（HuntVoidWatcher）と共通のキーです。
4. `/playermap`で地図を開閉できます。解除画面を閉じた場合も、同じコマンドで開けます。

初回の解除状態は保存されます。キーが変更された場合は、再入力が必要になります。
連続してキーを間違えた場合は、表示される待機時間が経過してから再試行してください。
利用キーは、このリポジトリやIssueに投稿しないでください。

## 更新

Dalamudのプラグインインストーラーから更新できます。
同じカスタムリポジトリURLをそのまま使用してください。

## 配布内容

- Dalamud API 15向け。
- `pluginmaster.json`: インストール・更新用の一覧。
- `PlayerMapping/<version>/latest.zip`: 版ごとの配布パッケージ。
- `DIST_VERSION.txt`: 現在の配布版。
- `SHA256SUMS.txt`: 現在のZIPのSHA-256。

ZIPは公開ダウンロードです。利用キーによる制限はプラグイン内で行います。
解除前は地図・設定・カウンターの表示、チャット集計、通知、外部データ取得を行いません。
このリポジトリにはソースコードや実行ログを含めません。
