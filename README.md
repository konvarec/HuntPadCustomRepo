# HuntPad（ハントパッド）

<img src="https://raw.githubusercontent.com/konvarec/HuntPadCustomRepo/main/images/huntpad-v2.png" alt="HuntPad icon" width="128" height="128">

**地図とカウンターで、モブハントをナビゲート。**

FFXIV / Dalamud向けの、モブハントのお供になる情報端末です。プレイヤー・モブ・FATEの地図表示、位置案内、Sモブトリガーカウンターで狩りを支援します。

## インストール

1. Dalamud設定の「試験的機能 / Experimental」にある「カスタムプラグインリポジトリ」に、次のURLを追加し、保存します。

   ```text
   https://raw.githubusercontent.com/konvarec/HuntPadCustomRepo/main/pluginmaster.json
   ```

2. プラグインインストーラーを開き直し、`HuntPad`をインストールします。
3. 初回に表示される画面で、配布元から案内された利用キーを入力してください。Observer（HuntVoidWatcher）と共通のキーです。
4. `/huntpad`で地図を開閉できます。解除画面を閉じた場合も、同じコマンドで開けます。従来の`/playermap`も使えます。

初回の解除状態は保存されます。キーが変更された場合は、再入力が必要になります。
連続してキーを間違えた場合は、表示される待機時間が経過してから再試行してください。
利用キーは、このリポジトリやIssueに投稿しないでください。

## 更新

Dalamudのプラグインインストーラーから更新できます。
旧配布リポジトリ`PlayerMappingCustomRepo`を使用していた場合は、カスタムリポジトリURLを上記の`HuntPadCustomRepo`のURLに変更してください。

旧名PlayerMappingから通常の更新でHuntPadに切り替わります。設定・利用キーの解除状態・ウィンドウ位置は引き継がれます。

## モブハントエリアの自動フィット

設定の「共通設定」にある「モブハントエリアのPOP位置に地図を自動フィット」をONにします（初期値OFF）。

- 登録済みのモブハント対象エリアで、全POP地点が収まる拡大率・表示位置に自動調整します。
- ウィンドウのサイズ変更に追従します。地点の観測済み状態やMOBPOS表示のON/OFFには左右されません。
- 自動調整中は手動のズーム・ドラッグを停止します。
- 自動調整値は保存済みの拡大率・位置を上書きしません。OFF時や対象外エリアでは保存済みの表示を使います。
- 対象エリアの地図をゲームデータと照合します。別の階層や地図切替中の不一致には適用しません。

## ラベルの間隔調整

共通設定の「ラベルの重なりを避ける」で回避のON/OFFを切り替えます。
「ラベルずらし間隔」は-5.00～5.00pxで、左右のドラッグで0.01px刻みに調整できます。Ctrl+クリックで直接入力もできます。
0は追加の余白なし、正の値は余白を追加します。負の値は文字サイズを変えずに縦の間隔を詰めます。たとえば-1.00なら0のときより1px詰めます。詰めすぎると文字や影が重なる場合があります。
小数点以下の指定は配置計算に反映しますが、画面上の見え方はフォントの描画にも左右されます。
以前の設定が5pxを超えていた場合は5pxに収めます。

## 配布内容

- Dalamud API 15向け。
- `pluginmaster.json`: インストール・更新用の一覧。
- `PlayerMapping/<version>/latest.zip`: 版ごとの配布パッケージ。
- `DIST_VERSION.txt`: 現在の配布版。
- `SHA256SUMS.txt`: 現在のZIPのSHA-256。
- `images/huntpad-v2.png`: プラグイン一覧用の512 x 512アイコン。SHA-256も上記ファイルに記録。

ZIPは公開ダウンロードです。利用キーによる制限はプラグイン内で行います。
解除前は地図・設定・カウンターの表示、チャット集計、通知、外部データ取得を行いません。
このリポジトリにはソースコードや実行ログを含めません。

## 0.1.0.19

- 設定の「共通設定」に「POP記録の診断情報をコピー」を追加。未発見の色に戻った際に、保存件数と表示中のインスタンスを確認できます。
- 設定の読み込みに失敗した場合、空の設定で上書きしないよう保護を追加。
- 自動リセットでインスタンス6～8を判定できず、同じ地図の全インスタンスの記録が消える問題を修正。応答は現在のホームワールド・地図・インスタンスと一致した場合だけ適用します。
- リロード後に古い通信結果が記録を変更することを防止。対象記録がない場合は、リセット前の復元データを維持します。

自動リセットOFFで色が戻る報告は、引き続き調査中です。発生時やリロード前後に、同じエリア・インスタンスで診断情報をコピーしてください。利用キーや連携URLは含まれません。

自動リセットを利用する場合は、設定画面の新しいApps Scriptを再デプロイしてください。スプレッドシートの`InstanceId`列は分割なし0、分割あり1～9です。列がない場合は`SName`中の番号を使用し、番号不明の応答ではリセットしません。
